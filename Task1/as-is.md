# As-Is: Медикаменте

Медцентр: 1 офис, 20 админ + 15 врачей. Данные в Excel/сканах на общем диске, 1С:Бухгалтерия + ККМ, 1С:Торговля и склад, Windows Server (AD/файлы/Exchange). Аудита доступа нет.

## Неучтённые / слабо учтённые конфиденциальные данные

| Данные | Где сейчас | В учётных системах? |
|--------|------------|---------------------|
| ФИО, ДР, телефон, email | Excel журналы, Outlook | частично |
| Адрес, работа/учёба | расширенные анкеты Excel | нет |
| Медкарты, диагнозы, назначения | Excel/PDF/JPG на шаре | нет (спецкатегория) |
| Результаты анализов | сканы на шаре | нет |
| Платежи пациентов | Excel + 1С БП + ККМ | частично (дубль) |
| Кадры / зарплата | 1С БП | да |
| ТМЦ / закупки | 1С ТиС | да (не ПДн) |
| Почта с вложениями ПДн | Exchange | нет контроля |
