# Данные × способы защиты

| Данные | Шифрование | Обфускация | Обезличивание |
|--------|------------|------------|---------------|
| ФИО, телефон, email | at-rest + TLS | маска в UI/логах | псевдоним в BI |
| Адрес / работа | at-rest | скрытие в печати | агрегаты по району |
| Диагноз, медкарта | field/file + KMS | watermark превью | не в BI сырьём |
| Анализы | file encrypt | — | агрегаты показателей |
| Платежи / чеки | TLS; 1С TDE/аналог | маска карты | агрегаты выручки |
| Кадры / зарплата | 1С at-rest | — | — |
| Логи / почта | TLS | DLP redact PII | хэш идентификаторов |
