## Ситуация

Сейчас: Excel, сканы на шаре, 1С (файловый режим), 1 сервер в офисе, IT = 3 чел.  
Цель: портал/EMR/API, рост ×5 и филиалы.

Затрагивает: запись, медкарта, оплата (ККМ), анализы, склад, отчёты; сервер, сеть, БД/файлы, интеграции, люди.

## Проблемы → риск для производительности

| Категория | Проблема | Эффект |
|-----------|----------|--------|
| Инфраструктура | 1 сервер, слабый IO, нет HA, общая сеть филиалов | тормоза и простой при росте |
| ПО / данные | Excel/сканы, 1С file, дубли | долгий/ломаный ETL, блокировки |
| Интеграция | OLE ККМ, Lab без лимитов, синхронные цепочки | каскадные таймауты |
| Персонал | мало IT, нет обучения, dual-run | ошибки и лишняя нагрузка |
| Процессы | big-bang, нет rollback и нагрузочных тестов ×5 | просадка после cutover |
| Безопасность | encrypt/audit/ABAC на горячем пути | лишний latency и I/O |

## Рекомендации (приоритет)

| P | Мера |
|---|------|
| **P0** | Поэтапная миграция (сначала запись, потом EMR, потом платежи) + план rollback |
| **P0** | Вынести БД с одного диска, бэкап отдельно, простой HA |
| **P0** | Чистить/сводить данные до ETL; нагрузочный тест ×5 до cutover |
| **P1** | Очередь вместо OLE; лимиты Lab API; меньше синхронных вызовов |
| **P1** | Шифрование и audit без KMS/записи на каждый read; кэш ABAC / отдельный путь ETL |
| **P2** | Обучение сотрудников; усиление IT; 1С → клиент-сервер |

## Итог

Узкие места — связка слабой инфры, грязных данных, синхронных интеграций и тяжёлых security-контролей. Сначала P0 (этапы, IO/HA, данные+тест), затем P1 (интеграции и «лёгкая» защита), потом P2 (люди и 1С).
